# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of **JSON_Lib** seriously. If you believe you have found a security vulnerability in this project, please report it responsibly:

1. **Do not disclose the vulnerability publicly** in a public issue, pull request, or discussion.
2. Please open a [GitHub Private Vulnerability Report](https://github.com/clockworkengineer/JSON_Lib/security/advisories/new) or contact the project maintainers directly.
3. Include detailed reproduction steps, proof-of-concept payloads (e.g. malformed JSON inputs), compiler version, and system architecture.

### What to Expect

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for triaging and patching the issue.
- Once fixed, a security advisory will be published and credit will be given to the reporter.
